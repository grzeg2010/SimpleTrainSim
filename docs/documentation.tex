\chapter{Application requirements}
\section{Short description}
Simple QT application that only shows train HUD.

\section{Detailed requirements}
\begin{enumerate}
    \item Application represents GUI which you could see on train HUD. It displays: speed in km/h, engine force, throttle setting, wheel slip warning, braking force in bars, brake setting, track gradient. Eventually acceleration
    \item In order to move locomotive has to fight track friction, rolling resistance, wind resistance and gravity.
    \item Cutting off the engine power at high speed should let the train roll and gradually slow down because of resistance forces.
    \item Starting resistance is higher (static friction).
    \item Too much force can cause the wheel to slide. Bad weather conditions can decrease the amount of force needed for wheels to start slipping.
    \item Gravity itself should be able to push the locomotive at the appropriate gradient.
    \item Wind resistance increases with speed. Every train holds a value of its aerodynamic efficiency.
    \item User will have to react to deadman's switch every few minutes dependant on train model.
\end{enumerate}
