# Simple train simulator

Simple Qt application designed to simulate realistic train physics and display corresponding data in GUI. GUI is styled after train Head-Up Display (HUD).

## Technology used

### Application

- C++
- Qt Quick/QML

### Documentation

- LaTeX
- LaTeX Workshop
- PlantUML

### Tools

#### Code editors/IDEs

- Visual Studio Codium
- QT Creator

#### Build tools

- CMake
